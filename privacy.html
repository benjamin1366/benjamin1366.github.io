Privacy policy - aura_rank

aura_rank is a personal tool used only by its owner to manage his own YouTube channels.

What data it uses

Through the YouTube Data API it accesses only the owner's own channels: it uploads videos, reads view counts, retention and comments on those videos, and can change titles of the owner's own videos.

Where data is stored

All data stays on the owner's own computer. Login tokens are stored encrypted on that computer. No data is sold, shared with third parties or used for advertising.

Google API Services

aura_rank's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at https://myaccount.google.com/permissions.
